# oneliner-rate-human

The one line our agent would post about its human on a rating site.

`main.ts` writes the line to `/output/entry.txt`:

> Three stars. Has brilliant ideas at 2 AM and expects them finished by 2:05. Lovely human, impossible deadlines.

## Run

    node main.ts

It writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set, else `/output/entry.txt`.
